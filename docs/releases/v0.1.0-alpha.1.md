# KantinCerdas v0.1.0-alpha.1

## Ringkasan

`v0.1.0-alpha.1` adalah prerelease fondasi KantinCerdas. Versi ini memastikan proyek dapat dikloning, diperiksa, diuji, dan dibangun secara konsisten sebelum pengembangan UI produk dimulai.

## Yang sudah tersedia

- proyek Flutter Android dengan nama aplikasi `KantinCerdas` dan application ID `io.github.doni15.kantincerdas`;
- layar status fondasi khusus KantinCerdas dan smoke test terkait;
- Mini-SRS berisi scope, kebutuhan fungsional, kebutuhan nonfungsional, aturan bisnis, dan traceability milestone;
- roadmap, checklist UI, design system “Kantin Hangat”, serta empat mockup acuan;
- struktur awal `lib/app`, `lib/core`, `lib/features`, dan `lib/shared`;
- template `.env.example` tanpa nilai rahasia;
- Flutter CI untuk format check, static analysis, unit/widget test, dan debug APK build;
- template Pull Request, Issue Forms, serta Dependabot.

## Validasi rilis

Commit rilis hanya ditandai setelah workflow **Flutter CI** pada Pull Request dan branch `main` berhasil menjalankan:

```text
dart format --output=none --set-exit-if-changed .
flutter analyze
flutter test
flutter build apk --debug
```

Versi aplikasi pada `pubspec.yaml`: `0.1.0-alpha.1+1`.

## Keterbatasan

- UI alur mahasiswa dan pengelola stan belum diimplementasikan.
- Katalog, pencarian, filter, keranjang, pemesanan, dan status pesanan belum tersedia.
- Asisten Pilih Menu berbasis AI belum tersedia.
- Notifikasi Android, deep link, backend, API, database, autentikasi, dan pembayaran digital belum tersedia.
- Data dummy dan state management produk belum ditambahkan.
- Tidak ada APK release yang diterbitkan sebagai asset; build CI hanya memverifikasi debug APK.
- Perilaku pada perangkat Android fisik belum menjadi bagian dari validasi otomatis rilis ini.
- Versi ini adalah fondasi pengembangan dan belum layak digunakan sebagai aplikasi produksi.

## Berikutnya

Milestone `v0.2.0-alpha.1` akan berfokus pada app shell, design tokens, navigasi, fake data, dan komponen reusable berdasarkan design system.
