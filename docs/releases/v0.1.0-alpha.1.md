# KantinCerdas v0.1.0-alpha.1

Tanggal rilis: 4 September 2026

Status: prerelease

## Ringkasan

`v0.1.0-alpha.1` adalah rilis fondasi pertama KantinCerdas. Rilis ini
menetapkan proyek Flutter Android, acuan produk dan desain, serta quality gate
awal sebelum UI produk mulai dikembangkan.

## Yang tersedia pada rilis ini

- proyek Flutter Android dengan nama `KantinCerdas` dan application ID
  `io.github.doni15.kantincerdas`;
- layar status fondasi dan smoke test terkait;
- Mini-SRS, roadmap, checklist UI, design system “Kantin Hangat”, dan empat
  mockup acuan;
- struktur awal `lib/app`, `lib/core`, `lib/features`, dan `lib/shared`;
- `.env.example` tanpa credential;
- Flutter CI untuk format, analisis statis, test, dan debug APK build;
- template Pull Request, Issue Forms, dan konfigurasi Dependabot.

## Validasi rilis

Commit rilis telah melewati Flutter CI dengan pemeriksaan berikut:

```text
dart format --output=none --set-exit-if-changed .
flutter analyze
flutter test
flutter build apk --debug
```

Versi aplikasi: `0.1.0-alpha.1+1`. Annotated tag
`v0.1.0-alpha.1` menunjuk ke commit
`2ac006859d57b83e3c575bd7427cf73e9f187acf`.

Penerbitan prerelease pertama diselesaikan oleh workflow sekali pakai. Workflow
tersebut kemudian dipensiunkan pada `v0.1.0-alpha.2`; Flutter CI tetap menjadi
quality gate aktif.

## Keterbatasan

- UI alur mahasiswa dan pengelola belum diimplementasikan.
- Katalog, pencarian, filter, keranjang, pemesanan, status pesanan, data dummy,
  dan state management produk belum tersedia.
- Asisten Pilih Menu, notifikasi Android, deep link, backend, API, database, dan
  autentikasi belum tersedia.
- Tidak ada APK distribusi yang diterbitkan; debug APK hanya digunakan untuk
  validasi build.
- Perilaku pada perangkat Android fisik belum diverifikasi.
- Rilis ini belum ditujukan untuk penggunaan produksi.

Perapian fondasi berikutnya dicatat pada
[`v0.1.0-alpha.2`](v0.1.0-alpha.2.md).
