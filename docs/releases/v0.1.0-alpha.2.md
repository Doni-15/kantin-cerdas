# KantinCerdas v0.1.0-alpha.2

Tanggal rilis: 4 September 2026

Status: prerelease

## Ringkasan

`v0.1.0-alpha.2` hanya merapikan fondasi kolaborasi, struktur source, dan
dokumentasi rilis. Rilis ini tidak menambahkan fitur produk atau mengubah
tampilan layar status fondasi.

## Perubahan

- menjadikan `lib/main.dart` entry point saja;
- memisahkan `KantinCerdasApp` dan layar status fondasi ke `lib/app`;
- mengganti placeholder `.gitkeep` pada folder kosong dengan README singkat
  tentang tanggung jawab dan batas dependency;
- menyesuaikan widget test dengan import app yang baru;
- menata kebijakan, rencana, dan riwayat di `docs/releases`;
- memensiunkan workflow penerbitan `v0.1.0-alpha.1` yang sudah selesai sambil
  mempertahankan Flutter CI;
- menyelaraskan dokumentasi kolaborasi dan metadata GitHub untuk fase `v0.1`.

## Validasi

Validasi lokal dan Flutter CI menjalankan:

```text
flutter pub get
dart format --output=none --set-exit-if-changed .
flutter analyze
flutter test
flutter build apk --debug
```

Versi aplikasi: `0.1.0-alpha.2+2`.

## Integritas rilis

- Tag `v0.1.0-alpha.1` tetap menunjuk ke commit rilis awal dan tidak diubah.
- Tag `v0.1.0-alpha.2` dibuat dari commit `main` hanya setelah Flutter CI pada
  commit tersebut berhasil.
- GitHub Release diterbitkan sebagai prerelease dan tidak menyertakan debug APK.

## Keterbatasan

- Layar yang tersedia tetap hanya status fondasi; app shell dan UI produk belum
  tersedia.
- Design tokens “Kantin Hangat”, navigasi, fake data, dan reusable components
  masih merupakan rencana [`v0.2.0-alpha.1`](NEXT.md).
- Katalog, pemesanan, AI, notifikasi, backend, API, database, dan autentikasi
  belum tersedia.
- Perilaku pada perangkat Android fisik belum diverifikasi.
- Rilis ini belum ditujukan untuk penggunaan produksi.
