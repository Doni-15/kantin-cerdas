# KantinCerdas — Paket Redesign UI/UX

Paket ini berisi 88 gambar individual sesuai seluruh ID pada brief:

- 1 papan komponen (`F00`)
- 37 layar mahasiswa (`M01–M37`)
- 18 layar pengelola (`P01–P18`)
- 9 layar pendukung (`U01–U09`)
- 17 kondisi sistem (`S01–S17`)
- 6 variasi ukuran/konten (`Q01–Q06`)

Folder `screens/` berisi ekspor PNG resolusi tinggi. `index.html` adalah galeri interaktif untuk menelusuri semua layar. Dataset, total, status, pola cart satu stan, checkout tunai, dan alur pesanan mengikuti brief terkunci.
